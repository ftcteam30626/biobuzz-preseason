# 30626 FTC Pre-Season Learning 2026-27

This repository is an pre-season learning project for Team 30626. 

## Software Goals

- Build a mecanum drivetrain that can move predictably around the field.
- Detect and localize pollens on the field, then generate paths to reach them.
- Control an intake alongside a linear slide mechanism.

## Getting Started

1. Open this repository in Android Studio.
2. Let Gradle sync the project.
3. Add robot code under `TeamCode/src/main/java/org/firstinspires/ftc/teamcode`.
4. Build and deploy to a Robot Controller device from Android Studio.
